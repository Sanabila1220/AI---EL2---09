# Artificial Intelligence (AI) - EL2 - 09

## 1. Introduction

This repository contains an Artificial Intelligence (AI) assignment covering three main topics: Expert Systems, Search Algorithms, and Multi-Agent Systems.

The objectives are to understand the basic concepts, working principles, and applications of each topic in the field of Artificial Intelligence.

### Topics
- **Expert System:** An AI system that uses knowledge and rules to solve problems or make decisions in a specific domain.
- **Search Algorithm:** A method used to explore possible states or solutions to find a goal or solve a problem.
- **Multi-Agent System:** A system consisting of multiple intelligent agents that interact, cooperate, or compete to achieve specific objectives.
